# Сервис поиска игроков для настольных игр пр1

## Назначение

Приложение помогает любителям настольных игр находить компанию для игры.
Пользователь создаёт заявку с названием игры, городом и количеством нужных
игроков, к заявке присоединяются другие пользователи, и на её основе
формируется встреча — конкретное место и время игры.

## Целевая аудитория

Любители настольных игр, которым не хватает постоянной компании для игры:
студенты, участники локальных клубов настольных игр, новые жители города,
желающие найти единомышленников рядом с собой.

## Предметная область

Сервис для поиска и организации совместных игровых встреч по настольным
играм. Пользователи указывают, в какую игру хотят сыграть, сколько игроков
не хватает и в каком городе они находятся, после чего заявка превращается
в реальную встречу с участниками, местом и временем проведения.

## Основные сущности

- **Пользователь** — участник сервиса (имя, город, любимые игры, рейтинг).
- **Игра** — настольная игра (название, минимальное и максимальное число
  игроков, длительность партии, сложность).
- **Заявка** — запрос на поиск игроков под конкретную игру (автор, игра,
  город, необходимое количество игроков, статус).
- **Встреча** — организованная игровая сессия, созданная на основе заявки
  (дата, место, участники, статус).

## Основные функции

- создание заявки на поиск игроков под выбранную игру;
- проверка статуса заявки (открыта / закрыта);
- расчёт количества свободных мест на встрече;
- формирование сводной информации о встрече для участников.

## План развития

На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
