## 3. Настройка рабочего окружения

- **Python:** версия 3.12.2, установлен и проверен командой `python --version`.
- **IDE:** VS Code (расширение Python).
- **Виртуальное окружение:** создано командой `python -m venv venv` в
  корне проекта; каталог `venv/` добавлен в `.gitignore` и не попадает в
  репозиторий.
- **Запуск программы:** проверен командой `python main.py`.
- **Git:** репозиторий инициализирован командой `git init`, подключён
  удалённый репозиторий на GitHub (`git remote add origin `), изменения
  отправлены командой `git push`.

Основные использованные команды:

```bash
python --version
python -m venv venv
python main.py
git init
git add README.md .gitignore main.py
git commit -m "Начальная реализация проекта"
git remote add origin git@github.com:talovns/django.git
git push -u origin master
```

## 4. Индивидуальный проект

- **Название проекта:** Сервис поиска игроков для настольных игр
- **Предметная область:** поиск и организация совместных игровых встреч по
  настольным играм — пользователь создаёт заявку на поиск игроков под
  конкретную игру, а на её основе формируется встреча с участниками, местом
  и временем.
- **Основные сущности:** Пользователь, Игра, Заявка, Встреча.
- **Реализованный на ПР1 функционал:** подготовлена структура репозитория
  (`README.md`, `.gitignore`, `main.py`), настроено виртуальное окружение,
  заполнен `README.md` по шаблону практической работы, реализован
  начальный сценарий — проверка заявки на поиск игроков и расчёт
  количества свободных мест на встрече. Реализованы функции:
  `get_request_status`, `calculate_free_slots`, `can_join_meeting`,
  `format_meeting_info`.
- **Ссылка на Git-репозиторий:** https://github.com/talovns/django
